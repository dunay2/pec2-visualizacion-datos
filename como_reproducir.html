Método y archivos reutilizables

Reproducir los gráficos con nuevos datos

Los gráficos se generan con funciones de bibliotecas disponibles públicamente. El cuaderno permite seguir el proceso, cambiar los CSV y volver a ejecutarlo.

TécnicaFunciónResultado

Candlestick chartplotly.graph_objects.CandlestickUna vela nativa por sesión, con apertura, máximo, mínimo y cierre.

Versiones de referencia: Plotly 6.3.0 y Seaborn 0.13.2. El archivo requirements.txt fija también las demás dependencias del ejemplo.

1. Descargar el cuaderno y los datos

Descarga y descomprime el paquete reproducible completo. Incluye el cuaderno, el generador, las dependencias, los CSV con sus metadatos, las figuras JSON/SVG y las pruebas de reutilización. Los HTML autónomos se crean al ejecutar el generador, para mantener pequeña la descarga.

También puedes descargar por separado el cuaderno, generar.py y requirements.txt en una misma carpeta. Dentro, crea una subcarpeta data y guarda los tres CSV con estos nombres:

  • data/epa_canarias.csv
  • data/taiex.csv
  • data/penguins_original.csv — conserva las 344 filas originales; el programa excluye las dos masas ausentes.

El cuaderno permite trabajar con archivos locales o con las URL públicas indicadas en su configuración. Para reproducir el ejemplo con una copia controlada de los datos, usa los archivos descargados.

2. Preparar Python y ejecutar

Con Python instalado, abre una terminal en esa carpeta e instala las dependencias en un entorno de trabajo. Jupyter es la interfaz para ejecutar el cuaderno; el generador ofrece el mismo proceso desde la terminal.

python -m pip install -r requirements.txt
python -m pip install jupyterlab
python -m jupyter lab

Abre PEC2_visualizaciones.ipynb y ejecuta las celdas en orden. La primera sección reúne la configuración. Para usar el script directamente:

python generar.py

Al ejecutar el generador, la carpeta output contiene las tres figuras HTML, sus JSON, los datos empleados, las coordenadas del beeswarm y tablas de resumen. Los HTML generados incluyen Plotly y pueden abrirse en un navegador sin cuenta ni conexión. Estas páginas del sitio cargan Plotly desde su CDN y mantienen las tablas disponibles sin JavaScript. Los JSON, CSV y SVG auxiliares ya están incluidos en el ZIP.

3. Sustituir los CSV

En la sección 1, cambia CSV_ENTRADA para señalar tus archivos. Si tus cabeceras son diferentes, cambia el lado izquierdo del diccionario COLUMNAS, conservando a la derecha los nombres utilizados por el programa.

Estructura mínima esperada para cada técnica.
TécnicaColumnas utilizadasCondición de los datos
Pie chartcategory, thousandsUna fila por categoría, cantidades no negativas y un total positivo. Las categorías deben formar un total coherente. El programa vuelve a calcular las proporciones.
Candlestickdate, open, high, low, closeUna fila por sesión; fechas YYYY-MM-DD; valores numéricos en una misma unidad. Apertura y cierre deben quedar entre mínimo y máximo.
Beeswarmspecies, body_mass_gUna observación por fila, una categoría y una medida numérica. El programa excluye únicamente los casos cuya medida está ausente.

Los nombres internos pueden conservarse aunque cambie el tema: por ejemplo, puedes asociar tiempo_entrega con body_mass_g. En ese caso cambia también el título y la unidad para que la figura describa tiempos de entrega, no masas de pingüinos.

4. Actualizar títulos, unidades y metadatos

Cambia TITULOS, UNIDAD_PIE, UNIDAD_VELAS y UNIDAD_SWARM en la primera sección del script o del cuaderno. Para el beeswarm, ETIQUETA_VALOR_SWARM, SUFIJO_VALOR_SWARM y DECIMALES_SWARM controlan el eje, la información del cursor y las medianas. Revisa el orden de las categorías y los colores cuando lo necesites.

Al compartir un conjunto diferente, documenta su fuente y URL, autoría, licencia, fecha de consulta, periodo y ámbito, unidades, población o muestra y transformaciones realizadas. En el pie explica el denominador; en las velas, la duración de cada intervalo; en el beeswarm, las observaciones excluidas.

Los metadatos entregados describen los ejemplos de esta PEC: EPA, TAIEX y Palmer Penguins. Para otros datos, crea o actualiza la documentación correspondiente y el README. La fuente, la licencia y las conclusiones de las páginas no se deducen automáticamente del CSV.

5. Conservar la geometría del beeswarm

Las posiciones calculadas por Seaborn dependen del tamaño del gráfico y de los puntos. En este ejemplo se conservan 1100 × 550 píxeles, con ejes fijos y desplazamiento horizontal en pantallas pequeñas. Plotly añade la interacción sin volver a colocar las observaciones.

Con otros valores, cambia RANGO_SWARM a "auto" o elige extremos que incluyan todos los casos. Si el programa avisa de que no caben todos los puntos, reduce TAMANO_SWARM_PT o aumenta ANCHO/ALTO y ejecuta de nuevo la colocación y la exportación. No escales después únicamente la figura de Plotly.

6. Revisar y compartir los nuevos resultados

Abre los tres HTML de output y contrasta sus valores con las tablas. Revisa las unidades, los títulos, los casos excluidos y el alcance de las conclusiones. El programa también guarda output/verificacion.json con los controles numéricos y las versiones empleadas.

Comparte el cuaderno, los CSV, sus metadatos y las dependencias junto con las figuras. Si reutilizas las páginas explicativas de este sitio, actualiza sus tablas, fuentes y comentarios para que correspondan a los nuevos datos; ejecutar el generador produce los archivos de output, pero no reescribe esas páginas de contexto.

El ZIP completo incluye tests/verificar.py, tres CSV expresamente ficticios y el informe de las pruebas. Desde la carpeta descomprimida puedes ejecutar python tests/verificar.py; los auxiliares de output y tests se distribuyen dentro del paquete.
